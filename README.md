# FaceID Attendance & Payroll System

## Overview
The **FaceID Attendance & Payroll System** is a web application designed to streamline attendance tracking and payroll management using face recognition technology. It offers features for employee login, attendance recording, payroll processing, and comprehensive reporting.

## Features
- **User Authentication**: Secure login for employees and administrators.
- **Face Recognition**: Use of face recognition technology for clocking in and out.
- **Attendance Management**: Track attendance records and generate monthly reports.
- **Payroll Processing**: Automated payroll calculations based on attendance data.
- **Admin Dashboard**: Manage employees, settings, and view analytics.
- **Data Management**: Export and clear all system data.

## Technologies Used
- **HTML/CSS**: For structure and styling of the web interface.
- **JavaScript**: For client-side scripting and interactivity.
- **Face-api.js**: For implementing face recognition functionality.
- **IndexedDB**: For data storage and management within the browser.

## Installation
To run the application locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd faceid-attendance-payroll
   ```

2. **Open the HTML file**:
   You can simply open the `index.html` file in a modern web browser that supports ES6 JavaScript and IndexedDB.

3. **Enable HTTPS**:
   For face recognition features to work, serve the application over HTTPS. You can use local servers like Live Server or HTTP-server.

## Getting Started
1. **Login as Admin**:
   - Username: `admin`
   - Password: `admin123`

2. **Add Employees**:
   Navigate to the Employees tab and add employee details including name, email, phone, and salary.

3. **Face Registration**:
   After adding employees, register their faces for use in the attendance system.

4. **Clock In/Out**: 
   Employees can use their registered faces to clock in or out.

5. **Process Payroll**:
   Admins can initiate payroll processing at the end of each month based on attendance data.

## Usage
- **Dashboard**: View total employees, attendance stats, and quick actions.
- **Attendance Page**: Filter and view attendance records by date.
- **Payroll Page**: Generate and manage payroll for the designated month, including processing and exporting options.
- **Reports Page**: Generate detailed reports on attendance and payroll summaries.
